# E2E環境のセットアップ

`uapp_e2e/SETUP.md`（AI向けセットアップランブック）を読み、その手順を上から実行する。

- 環境検出（Unityバージョン/package/画面向き/NGUI有無/AVD/エディタ）は**必ず実物のファイル・コマンドから読む**（推測しない）
- プロジェクト設定の変更は最小限・可逆に。迷う変更は実行前にユーザーへ提示
- 最後に必ずビルド→ping疎通まで実際に動かして検証し、変更ファイル一覧を報告する

キットがまだ無い場合（GitHub URLやzipを渡された場合）は、ユーザーの許可を得て取得・展開し、
`scripts\install-to-project.ps1 -ProjectPath <対象>` で配置してから SETUP.md に従う。
